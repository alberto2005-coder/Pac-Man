# Pac-Man en HTML, CSS y JavaScript

¡Este es un **clon básico de Pac-Man** hecho únicamente con HTML, CSS y JavaScript!  
Puedes jugar desde el navegador sin necesidad de instalar nada adicional.

---

## 🎮 Cómo jugar

- Presiona el botón **INICIAR JUEGO** para comenzar.  
- Usa las flechas del teclado para mover a Pac-Man:
  - `↑` Flecha arriba
  - `↓` Flecha abajo
  - `←` Flecha izquierda
  - `→` Flecha derecha
- Come todos los puntos para ganar.  
- Come **Power Pellets** (círculos grandes) para que los fantasmas se pongan asustados y puedas comerlos.  
- Si un fantasma te atrapa sin estar asustado, pierdes una vida.  
- El juego termina cuando pierdes las 3 vidas o ganas al comer todos los puntos.

---

## 🕹️ Controles

- Teclas de dirección: mover a Pac-Man  
- Botón **INICIAR JUEGO**: comenzar o reiniciar partida

---

## 🗂️ Archivos del proyecto

- `index.html` → Estructura del juego  
- `styles.css` → Estilos del tablero, Pac-Man y fantasmas  
- `script.js` → Lógica completa del juego  
- `logo.png` → Icono del juego (opcional)  

---

## 💻 Cómo ejecutar

1. Clona o descarga este repositorio.  
2. Abre el archivo `index.html` en tu navegador web (Chrome, Firefox, Edge…).  
3. ¡Presiona **INICIAR JUEGO** y comienza a jugar!

---

## ⚡ Características

- Tablero dinámico con puntos y power pellets.  
- Movimiento de Pac-Man con animación de dirección.  
- Fantasmas con inteligencia artificial básica:
  - `Blinky` (rojo) persigue directamente a Pac-Man  
  - `Pinky` (rosa) embosca adelantándose a Pac-Man  
  - `Inky` (cian) usa estrategia combinada  
  - `Clyde` (naranja) persigue o huye según distancia  
- Cambio de modo `scatter` y `chase` cada cierto tiempo.  
- Sistema de puntuación y vidas.  

---

## 📥 Descargar

1. Haz clic en el botón **Code** en GitHub y selecciona **Download ZIP**.  
2. Extrae el archivo ZIP en tu computadora.  
3. Abre `index.html` para jugar.
